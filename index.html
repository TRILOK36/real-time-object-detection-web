Real-Time Object Detection Platform

A computer-vision project that finds people and everyday objects in a live camera feed, draws boxes around them, and records each detection. Try the browser demo below with your own webcam. The video never leaves your device.

How the full project works

  1. CaptureOpenCV reads frames from the webcam in real time.
  2. DetectYOLOv8 finds objects, with a class filter and confidence threshold.
  3. LogEach detection is saved to a MySQL table with its time, class, confidence and box.
  4. ShowA Streamlit dashboard displays the live feed, metrics and the latest logs.

This website runs a lightweight in-browser version of the detector. The Python, YOLOv8 and MySQL platform runs locally; see the repository and demo video below.
